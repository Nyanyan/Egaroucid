# Multi-ProbCut（MPC）の浅い探索深度・標準偏差モデル・枝刈り確率の比較

この文書は、変更内容ごとの測定値を比較するためのレポートである。採用する設定は決めない。最初に主要結果を示し、その後に測定条件と全結果を示す。

## 主要結果

| 変更内容 | 実行ファイルで得た主な数値 | この数値から直接言えること |
|---|---|---|
| 中盤の標準偏差モデルを再推定し、浅い探索深度を変えない候補 | 固定深度の時間比1.0034、2石以上の着手損失7件、4石以上1件。現行は時間比1.0000、7件、1件。1手100ミリ秒対戦の組スコア率49.22%、95%信頼区間44.92%～53.52%。 | 固定深度では現行とほぼ同じ時間・着手精度だった。対戦の信頼区間は50%を含む。 |
| 中盤の浅い探索深度だけを変更 | 固定深度では全候補の時間比が1を超えた。1手100ミリ秒対戦では全4候補の95%信頼区間が50%を含んだ。 | 測定した候補には、固定深度の時間を現行より減らした設定がない。対戦だけでは候補間の優劣を確定できない。 |
| 終盤19手以上の標準偏差モデルを再推定 | 1手15秒・65局面の読み切りは現行38局面、開始局面均等候補36局面、探索深度範囲均等候補34局面。30マス空きの時間総和比はそれぞれ1.0641と1.1180。 | この測定では両候補とも現行より読み切り数が少なく、両方が完了した条件の合計時間も多い。 |
| 終盤MPCの浅い探索深度を変更 | 1手15秒・65局面の読み切りは現行38、−2手37、再学習±0手34、+2手33、+4手27。 | この測定では全候補の読み切り数が現行より少ない。 |
| 分位点 `z` へ0.98を掛けた参考測定 | 中盤固定深度の時間比0.9488。2石以上の着手損失4件、4石以上0件、平均着手損失0.018で、同じ測定群の現行と同数。 | この100局面測定では時間が5.12%減り、表にある着手精度指標は変わらなかった。固定倍率機能は現在の本体プログラムに入っていない。 |

## 表を読む順序

1. 実行ファイルで測った時間は、`合計探索時間`、`時間比`、`1手100ミリ秒対戦`、`1手15秒`の表で確認する。`推定訪問局面数比`は実行時間ではない。
2. 固定深度では、時間比と訪問局面数比が1未満なら現行より小さく、探索速度比が1を超えれば現行より1秒当たりの処理局面数が多い。着手損失は小さい方、完全読みとの着手一致率は大きい方が正確である。
3. 固定時間対戦では、組スコア率50%が同点である。95%信頼区間が50%を含む場合、この対戦数だけでは優劣を確定できない。
4. 同じ表の現行と候補だけを比較する。局面集合や測定条件が異なる別表の絶対時間は直接比較しない。

## 用語の定義

用語を先にすべて読む必要はない。表で不明な語が出たときに参照できるよう、厳密な定義と平易な説明を併記する。

### 探索処理

| 用語・記号 | 厳密な定義 | 平易な説明（つまり何か） |
|---|---|---|
| 評価値 | 探索または評価関数が返す、石差単位の数値。同じ局面・同じ手番から比較し、値が大きい手を上位とする。 | ある手が別の手より何石分よいと計算されたかを表す数値。 |
| 石数・マス空き | 石数は盤上で黒石または白石が置かれているマスの合計。マス空きは `64−石数`。 | ゲームがどこまで進んだかを表す。マス空きが少ないほど終局に近い。 |
| 探索深度 | 探索が先の着手を再帰的に調べる回数を指定する整数。深度を1増やすと、原則として着手を1回先まで追加して調べる。 | 何手先まで調べるかを表す数値。 |
| 静的評価 | 子局面を生成する探索を行わず、評価関数を現在局面へ1回適用して評価値を得る処理。 | 先を読まず、現在の盤面だけで点数を付ける処理。 |
| 探索窓 `[α, β]` | アルファ・ベータ探索へ渡す下限 `α` と上限 `β`。探索結果を `α` 以下、`α` と `β` の間、`β` 以上のいずれかとして扱う。 | 評価値の全範囲ではなく、判定に必要な境界だけを指定する仕組み。 |
| 通常窓探索 | `β−α` が1より大きい探索窓を使い、窓内の評価値も求める探索。 | 境界を超えたかだけでなく、境界の間にある評価値も調べる探索。 |
| ゼロ窓探索 | 整数評価で `β=α+1` とし、評価値が境界以下か境界以上かだけを判定する探索。 | 指定した境界を超えるかだけを調べる探索。 |
| Multi-ProbCut（MPC） | 浅い探索値と誤差モデルから深い探索値が探索窓の外にあると判定した場合に、その深い探索を実行せず上限値または下限値を返す処理。 | 短い探索で境界を超えると判断できた場合に、長い探索を省略する処理。 |
| 深い探索深度 | MPCを使わない場合に、その探索呼出しが実行する予定の探索深度。 | MPCが省略できるか判定する対象の探索深度。 |
| 浅い探索深度 | MPC判定の入力値を得るため、深い探索より先に実行する探索の深度。 | 深い探索を省略できるか調べるために先に読む深度。 |
| MPC判定機会 | 局面、探索窓、深い探索深度、浅い探索深度、選択率が1組与えられ、MPC条件を1回評価したこと。 | MPCが深い探索を省略するか判断した回数。 |
| 枝刈り | MPC判定により深い探索を実行せず、評価値が探索窓の上側または下側にあるという境界値を返すこと。 | 深い探索を省略したこと。 |
| 誤った枝刈り | 上側へ枝刈りしたのに完全読み値が上側境界未満だった場合、または下側へ枝刈りしたのに完全読み値が下側境界を超えていた場合。 | 省略してよいというMPCの判定が完全読みと矛盾した回数。 |
| 誤った枝刈りの割合 | `誤った枝刈り回数÷枝刈り回数×100`。枝刈り回数が0の場合は0とする。 | 深い探索を省略した全回数のうち、完全読みと矛盾した割合。 |
| 予測誤差幅を2石以上・4石以上超過 | 残差を `r`、予測した整数誤差幅を `m` とし、`max(0,abs(r)−m)` が2以上または4以上だった誤差標本数。 | 浅い探索の実際の誤差が、予測した範囲を2石以上または4石以上超えた回数。 |
| 誤った枝刈りが境界から2石以上・4石以上 | 上側の誤枝刈りでは `上側境界−完全読み値`、下側の誤枝刈りでは `完全読み値−下側境界` が2以上または4以上だった回数。 | MPCの誤判定が探索窓の境界から2石以上または4石以上離れていた回数。 |
| 浅い探索実行 | MPC判定機会のうち、静的評価による事前条件を満たし、MPC判定用の浅い探索を実際に呼び出した回数。 | MPC判定のための浅い探索を実行した回数。 |
| 訪問局面数 | 探索関数が処理した局面の延べ回数。実装内部の `nodes` と同じ値。 | 探索中に計算した局面数。通常は少ないほど計算量が少ない。 |
| 探索速度 | `合計訪問局面数÷合計探索秒数`。単位は局面/秒。 | 1秒に何局面を処理したか。大きいほど同じ時間で多く計算している。 |
| 置換表 | 探索済み局面を盤面識別値で検索し、その評価値・探索深度・境界種別・着手を再利用する表。 | 同じ局面を再計算しないための探索結果の保存領域。 |
| 置換表容量設定 | 実行ファイルが置換表の要素数を決めるために受け取る整数設定値。 | 探索結果を何件保存できるかを決める実行設定。 |
| スレッド数・使用コア数・中央処理装置使用率 | スレッド数は並列に実行可能な処理単位数。使用コア数は測定中に計算へ使った物理コア数の時間平均。使用率は `使用コア数÷指定スレッド数×100`。 | 並列計算をいくつ指定し、そのうち平均していくつ分を実際に使ったかを表す。 |

### 誤差モデルと係数計算

| 用語・記号 | 厳密な定義 | 平易な説明（つまり何か） |
|---|---|---|
| 現行・候補 | 現行は比較基準の実行ファイルまたは設定。候補は比較する変更後の実行ファイルまたは設定。 | 表では現行を基準値1として、変更後が増減した量を読む。 |
| モデル・係数 | モデルは入力から予測値を計算する式。係数はその式へ代入する固定値で、この文書では `a`～`g` などで表す。 | モデルは計算式、係数は同じ入力に対する計算結果を決める数値。 |
| 係数再推定・学習 | 収集した誤差標本を目的関数へ代入し、その目的関数を最小にする係数を数値計算で求める処理。 | 実測した誤差に合うように、計算式の数値を決め直す処理。 |
| 重み `wᵢ` | 目的関数の第 `i` 標本の項へ掛ける非負の数値。重み付き平均は `Σwᵢxᵢ÷Σwᵢ`。 | 各標本を係数計算へどれだけ反映するかを指定する数値。 |
| 残差 `rᵢ` | 第 `i` 標本の `深い探索値−浅い探索値`。この実験では残差の平均を0と仮定する。 | 浅い探索値が深い探索値から何石ずれたか。 |
| 標準偏差 `σᵢ` | 第 `i` 標本についてモデルが予測する残差の二乗平均平方根。常に正の値を使う。 | その条件で浅い探索値が通常どの程度ずれると予測したか。 |
| 標準偏差モデル | 石数、浅い探索深度、深い探索深度を入力し、予測標準偏差 `σ` を返す式と係数の組。各節に実際の式を記載する。 | 盤面段階と探索深度から、浅い探索の誤差量を予測する計算式。 |
| 数式記号 `Σ`・`abs`・`sqrt`・`ceil`・`min`・`max`・`exp` | `Σ` は指定範囲の合計。`abs(x)` はxの絶対値。`sqrt(x)` は二乗するとxになる非負値。`ceil(x)` はx以上の最小整数。`min` と `max` は引数の最小値と最大値。`exp(y)` は `ln(x)=y` を満たす正のx。 | この文書の式で使う、合計・絶対値・平方根・切上げ・最小・最大・指数の計算。 |
| 自然対数 `ln(x)` | 正の `x` に対する `1` から `x` までの `1/t` の定積分。 | 目的関数で使用する数学関数。 |
| 正規分布 `N(0, σ²)` | 残差 `r` の確率密度を `exp(−r²÷(2σ²))÷(σ×sqrt(2π))` とする、平均0・分散 `σ²` の確率分布。`π` は円周率。 | 0に近い誤差ほど生じやすいという仮定。 |
| 標準正規分布 | 平均0、標準偏差1の正規分布 `N(0,1)`。 | 誤差を標準偏差で割った後に使う共通の確率分布。 |
| 分位点 `z` | 標準正規分布に従う変数を `Z` としたとき、指定確率 `q` に対して `P(Z≤z)=q` を満たす値。 | 選択率を石差の判定幅へ変換するための数値。 |
| 上側・下側分位点 | 標準化残差 `r÷σ` を昇順に並べ、指定した上側確率と下側確率に対応する位置から別々に求めた値。 | 浅い探索が大き過ぎる場合と小さ過ぎる場合の誤差量を別々に表す数値。 |
| 選択率 | MPC判定に使う中央確率。実装の各段階では対応する分位点 `z` が定まり、100%ではMPCを実行しない。 | 大きくすると深い探索を省略する回数が減り、誤った省略も通常は減る設定。 |
| 選択率レベル | 実装が複数の選択率を区別するために使う整数番号。表には番号と実際の選択率を併記する。 | 選択率を指定する実装内部の番号。 |
| 整数誤差幅 | 終盤の浅い探索では `ceil(1.10×分位点×σ−10⁻¹²)` で求める石差単位の整数。上側と下側を別々に計算する。 | MPC判定の境界へ加える石差。大きいほど枝刈り成立回数が減る。 |
| 誤差標本・開始局面群 | 誤差標本は1回のMPC判定機会から得た残差。開始局面群は同じ開始局面から派生した誤差標本の集合。 | 1個の誤差データと、同じ対局開始点から得た誤差データのまとまり。 |
| 5分割交差検証 | 開始局面群を5組へ分け、4組で係数を求め、残る1組で指標を計算する処理を、検証側を変えて5回行う方法。 | 係数を決めたデータとは別の部分でも誤差予測が合うかを確認する方法。 |
| 独立確認用データ | 係数、浅い探索深度、`λ`、`p` の選択へ使用せず、選択完了後の指標計算だけに使用するデータ。 | 設定決定に使わず、最後の確認にだけ使うデータ。 |
| 中盤係数再推定の目的関数 `J` | `J=Σwᵢ[ln(σᵢ)+rᵢ²÷(2σᵢ²)]÷Σwᵢ+λD`。`Σ` は全標本についての合計。係数は `J` を最小にするよう求める。 | 誤差予測の不一致と現行係数からの差を1個の数値にしたもの。小さい係数組を選ぶ。 |
| 現行係数との差 `D` | `D=Σ((θⱼ−θⱼ⁽⁰⁾)÷max(abs(θⱼ⁽⁰⁾),1))²`。`θⱼ` は候補係数、`θⱼ⁽⁰⁾` は現行係数、`max` は大きい方を返す関数。 | 候補係数が現行係数から変化した量を、係数ごとに尺度をそろえて合計した値。 |
| `λ` | 中盤の目的関数 `J` の項 `λD` で `D` に掛ける非負の値。今回の候補値は1、3、10。 | 目的関数の中で、現行係数との差を何倍で数えるかを指定する値。 |
| 現行式から生成した121個の追加データ | 石数を11段階、浅い探索深度を11段階にした121組について、現行式の `σ` を目標値として作成した終盤係数学習用データ。 | 実測データが少ない入力でも、現行式の値を係数計算へ含めるためのデータ。 |
| 追加データの合計重み `p` | 121個の追加データへそれぞれ `p÷121` を掛けたときの重みの合計。`p=0` では追加データを使わない。 | 121個の追加データ全体を係数計算へどれだけ反映するかを指定する値。 |
| 実測標準偏差 | 同じ条件の残差が `n` 個あるときの `sqrt(Σrᵢ²÷n)`。残差平均を0とする今回の仮定に対応する。 | 実際に観測した浅い探索誤差の大きさ。 |
| 正規分布負対数尤度 | 各標本の `ln(σᵢ)+rᵢ²÷(2σᵢ²)` の重み付き平均。全候補で同じ定数項は省く。 | 予測標準偏差と観測残差の一致を測る値。小さい方が一致している。 |
| 標準化残差の二乗平均平方根 | `sqrt(Σ(rᵢ÷σᵢ)²÷n)`。重み付きの場合は対応する重み付き平均を使う。 | 1に近いほど、予測した誤差量と観測した誤差量の全体的な大きさが一致している。 |
| 標準偏差予測の平均絶対誤差 | 条件ごとの予測標準偏差を `σ̂ₖ`、実測標準偏差を `sₖ`、条件数を `K` としたときの `Σabs(σ̂ₖ−sₖ)÷K`。 | 標準偏差の予測が平均で何石ずれたか。小さい方がよい。 |
| 標準偏差予測の二乗平均平方根誤差 | 条件数を `K` としたときの `sqrt(Σ(σ̂ₖ−sₖ)²÷K)`。 | 標準偏差予測の誤差を、大きなずれへ大きい比重を付けて集計した値。小さい方がよい。 |
| 固定倍率 | モデルが計算した全 `σ` または全分位点 `z` へ、入力条件に関係なく同じ数を掛ける変更。 | 係数を学習し直さず、判定幅だけを一律に変更する方法。 |

### 測定値

| 用語・記号 | 厳密な定義 | 平易な説明（つまり何か） |
|---|---|---|
| 固定深度測定 | すべての比較設定へ同一局面、同一探索深度、同一選択率集合を与える測定。 | 同じ深さまで読ませ、時間・訪問局面数・選んだ手を比べる測定。 |
| 局面×選択率 | `局面数×各局面で実行した選択率数` で求めた探索実行数。 | 表の合計値に含まれる探索の回数。 |
| 推定訪問局面数比 | `(浅い探索の訪問局面数+枝刈り不成立時の深い探索訪問局面数)÷全判定で深い探索した場合の訪問局面数`。 | 記録済みデータから計算した訪問局面数の比。実行時間の実測値ではない。 |
| 事後計算 | 保存済みの浅い探索値、完全読み値、訪問局面数を式へ代入して求め、候補実行ファイルを動かさない計算。 | 過去の記録から求めた値であり、実行ファイルの速度測定ではない。 |
| 訪問局面数比・時間比・探索速度比 | 同じ条件で `候補の値÷現行の値` とした比。 | 1で同じ。時間比と訪問局面数比は1未満なら候補が少なく、探索速度比は1超なら候補が速い。 |
| 総和比 | 現行と候補が両方完了した条件だけについて、`候補の合計÷現行の合計` とした比。 | 両方が完了した条件全体で、候補が現行の何倍だったか。 |

1. **標準偏差モデルの係数再推定**：中盤では `a`～`g`、終盤の深い探索深度19手以上では `a`～`f` を誤差標本から計算し直した。分位点 `z` は変更していない。

### 1.2 終盤の深い探索深度19手以上で使う a～f 係数

対象式は `x=石数÷64`、`y=浅い探索深度÷60`、`u=a×x+b×y`、`σ=c×u³+d×u²+e×u+f` である。主な使用箇所は深い探索深度19手以上であり、深い探索深度10～18手・選択率74%～93%の専用表とは別である。

`開始局面を均等に重み付けした係数`は、各開始局面群の標本数が違っても、1群当たりの学習への影響を同じにした候補である。`探索深度範囲を均等に重み付けした係数`は、深い探索深度10～18手、19～26手、30手などの収集元ごとに学習への影響を同じにし、さらに各収集元の中では開始局面群の影響を同じにした候補である。

係数再推定に使った新規データの中心は深い探索深度19～26手である。履歴データには深い探索深度10～18手があり、深さ30手は8局面を独立確認に使った。学習時は `ρ=−b`、`v=x+ρy` とした。石数と浅い探索深度の全範囲で得る `v` の最小値を `vₘᵢₙ`、最大値を `vₘₐₓ` とし、`t=(v−vₘᵢₙ)÷(vₘₐₓ−vₘᵢₙ)` としたため、tは0以上1以下になる。標準偏差は `σ=q₀(1−t)³+3q₁t(1−t)²+3q₂t²(1−t)+q₃t³` と表し、`q₀`～`q₃` をすべて0.5以上にした。q₀～q₃に掛かる `(1−t)³`、`3t(1−t)²`、`3t²(1−t)`、`t³` はそれぞれ0以上で、合計は1である。このため、すべてのtで `σ` は0.5以上になる。学習後に同じ `σ` を返す c～f を式の展開によって計算したため、探索中の計算手順は現行と同じである。学習用と各独立確認用データの間には、同じ開始局面、同じ盤面、盤面を回転または鏡映した盤面、黒石と白石を入れ替えた盤面の重複が0件だった。

`u=a×x+b×y` を一定倍し、c～fをその倍率に対応して変換すると、すべての入力で同じ `σ` を返す別の係数組を作れる。このため a～fを同時に自由変数にすると係数組が一意に決まらない。候補では a=-1に固定し、b～fだけを推定した。実測データに加え、用語表で定義した121個の追加データを使用した。表の `p` は追加データの合計重みであり、開始局面を均等に重み付けした候補は0.03、探索深度範囲を均等に重み付けした候補は3である。候補選択処理は `p=0` を比較対象から除外するよう実装されていた。`p=0` で計算した場合は両方の重み付け方法で b=-31.6665だった。したがって、下表の2候補は `p=0` を含む全設定から交差検証値だけで選んだ結果ではない。
