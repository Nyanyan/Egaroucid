# 再較正済み範囲外で使われる終盤 MPC 標準偏差式の再学習結果

## このレポートの対象

対象は `probcut_sigma_end(n_discs, shallow_depth)` の旧方式である。

```text
x = n_discs / 64
y = shallow_depth / 60
u = a*x + b*y
sigma = c*u^3 + d*u^2 + e*u + f
```

深い探索 10～18 手、選択率 74%・88%・93% には別の再較正済み表がある。このレポートは、その表ではなく次の箇所を測った。

- 深い探索 19 手以上で使う旧方式
- 深い探索 10～18 手で、選択率 98%・99%・99.9% に使う旧方式

係数を一つも変えずに出力値へ固定倍率を掛ける候補は含めていない。各再学習候補では、内側の一次式の比率と外側の三次式を一緒に再推定した。

このレポートは測定結果を表にするところまでとし、どの候補を本体へ入れるかは決めていない。本体ソースも変更していない。

## 学習方法

教師は `厳密値 - 浅い探索値` である。盤石数と浅い探索深さが同じ標本をまとめ、その二乗平均平方根を標準偏差の教師とした。平均誤差を別途引くモデルには変えていない。

二つの重み付けを比較した。

| 名前 | 重み付け |
|---|---|
| root_equal | 各 root の総重みを同じにする |
| domain_equal | 10～18 手、19～22 手、23～26 手の三つの深さ帯の総重みも同じにする |

無正則化では、狭い入力範囲内で大きい係数同士が相殺する形になった。そのため、現行曲線上の深さ 10～44 手の 35 点を補助標本にする候補も測った。補助標本の総重みは `0.1, 0.3, 1, 3, 10, 30` を root CV で比較し、両方の重み付けで Gaussian NLL が最小だった 3 を表に残した。これは最終 sigma へ 3 や一定倍率を掛ける処理ではない。補助標本を加えた後に `b,c,d,e,f` をもう一度同時に解いている。

### 係数の正規化

この式には係数の尺度に完全な冗長性がある。`a,b` を `k` 倍し、`c,d,e` をそれぞれ `k^-3,k^-2,k^-1` 倍しても sigma は全く同じである。そのため、六つ全部を独立に最適化したという表現は数学的にできない。

比較表では同じ関数を保ったまま `a=-1` に正規化し、識別できる残り五つの係数を比較した。現行実装の元の係数は別行として [coefficients.csv](results/coefficients.csv) に残してある。

| モデル | a | b | c | d | e | f |
|---|---:|---:|---:|---:|---:|---:|
| 現行を等価変換 | -1 | -5.304756 | -0.120966 | 0.839053 | 6.972914 | 11.940601 |
| root_equal | -1 | -3.942597 | 59.806161 | 221.514880 | 282.784155 | 127.622583 |
| root_equal + prior 3 | -1 | -4.512575 | 8.892217 | 40.173615 | 64.366775 | 39.327044 |

| domain_equal + prior 3 | -1 | -4.657995 | 3.082413 | 17.458257 | 35.016416 | 26.847616 |

## 5-fold root CV

`sigma RMSE/MAE` は、確認 fold 内で求めた実測の誤差 RMS と、モデルが予測した sigma の差である。`標準化 RMS` は `(厳密値-浅い探索値)/sigma` の RMS で、1 が誤差の大きさと sigma が一致した状態を表す。1 より大きいと sigma が小さすぎ、1 より小さいと sigma が大きすぎる。Gaussian NLL は小さい方がよい。

浅い探索値そのものは全モデルで同じなので、値の残差 RMSE は 4.6267 石、MAE は 3.5269 石で共通である。

| モデル | sigma RMSE | sigma MAE | 標準化 RMS | Gaussian NLL |
|---|---:|---:|---:|---:|
| 現行 | 0.7260 | 0.5953 | 0.9618 | 2.01960 |
| root_equal | 0.7021 | 0.5549 | 1.0055 | 2.01932 |
| root_equal + prior 3 | 0.7103 | 0.5813 | 0.9763 | 2.01891 |
| domain_equal | 0.7524 | 0.6139 | 1.0373 | 2.02647 |
| domain_equal + prior 3 | 0.7011 | 0.5640 | 0.9795 | 2.01878 |

全正則化強度の値は [cv_summary.csv](results/cv_summary.csv)、fold ごとの値は [cv_folds.csv](results/cv_folds.csv) にある。

## 枝刈りと推定ノード数

各 context について、実装と同じ次の判定を再現した。

```text
error = ceil(z[level] * sigma)
静的評価による浅い探索開始条件 = max(1, error - 3)
浅い探索の cut 境界 = alpha/beta ± error
```

`誤 cut` は、MPC が枝を切ったのに厳密値が alpha/beta 境界の反対側だった件数である。`2石以上` と `4石以上` は、厳密値と境界の差で数えた。

推定ノード比は次式である。

```text
(浅い探索を実行したときの浅い探索ノード数 + cut できなかったときの深い探索ノード数)
/ 全 context の深い探索ノード数
```

収集時の浅い探索は置換表を空にした full-window 探索であり、実戦の null-window 探索とはノード数が違う。したがって、これは候補間のオフライン比較値で、実機の経過時間や NPS ではない。

## 表から直接読める事実

- 5-fold root CV では、無正則化 root_equal の sigma RMSE/MAE が現行より小さかった。Gaussian NLL の差は `2.01960 → 2.01932` だった。
- 6 月 holdout でも root_equal の sigma RMSE/MAE は現行より小さかった。
- 新規の深さ 19～25 手 holdout と、8 局面の深さ 30 手確認では、現行の sigma RMSE/MAE と Gaussian NLL が全再学習候補より小さかった。
- 新規の深さ 19～25 手 holdout では、全候補で 2 石以上・4 石以上の誤 cut は 0 件だった。全候補に 1 件ある誤 cut は境界との差が 1 石未満または 1 石だった。
- 6 月 holdout の高選択率シミュレーションでは、無正則化 domain_equal の 98% に誤 cut が 1 件あり、2 石以上ではなかった。それ以外は誤 cut 0 件だった。
- 無正則化二候補は係数の絶対値が大きく、狭い入力範囲で項同士が相殺している。prior 3 の二候補は係数の絶対値が小さくなったが、新規 holdout の指標は現行を上回らなかった。
- 厳密値で確認できた最大深さは 30 手であり、GGS ログに多数ある 31 手以上について、係数精度を直接保証する厳密値データは今回ない。
