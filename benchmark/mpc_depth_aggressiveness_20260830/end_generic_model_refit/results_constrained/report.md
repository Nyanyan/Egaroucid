# 終盤 generic MPC 標準偏差モデルの正値制約付き再学習

## 何を変更したか

標準偏差に固定倍率を掛ける方法は使っていない。Egaroucid が計算する

```text
u = a * n_discs / 64 + b * shallow_depth / 60
sigma = c*u^3 + d*u^2 + e*u + f
```

の6係数 `a`～`f` を直接再学習した。尺度の重複を除くため `a=-1` とし、`b=-r` (`r>=0`) を探索した。

正値制約には3次 Bernstein 基底を使った。`v=-u` を `v=0` から `v=1+r` の区間で0～1へ正規化し、4個の Bernstein 係数をすべて0.5以上に制約した。Bernstein 基底は区間内で非負、かつ合計が1なので、この制約により区間全体で `sigma>=0.5` となる。したがって、`n_discs=0..64`、`shallow_depth=0..60` の3965通りだけでなく、その間の連続値でも正値になる。

4個の Bernstein 係数のうち、下限0.5に固定する係数の組合せを全16通り調べ、残りの係数を最小二乗で解いた。その後、通常の3次式へ変換して `c`～`f` を得た。

学習局面で観測されない表の領域における式の形を安定させるため、全領域の11×11点で現行モデルの予測値を弱い事前分布として加えた。強さは `0, 0.03, 0.1, 0.3, 1, 3, 10, 30` を5分割交差検証した。事前分布なしの値も表に残したが、最終候補の選択は正の事前分布強度だけから行った。

## 5分割交差検証

458 root、3277観測をroot単位で5分割した。`sigma RMSE/MAE` は、各 `(n_discs, shallow_depth)` で観測した誤差の実効標準偏差に対する誤差である。Gaussian NLLは小さい方が良い。

| モデル | sigma RMSE | sigma MAE | 誤差/sigma のRMS | Gaussian NLL |
|---|---:|---:|---:|---:|
| 現行 | 0.726037 | 0.595345 | 0.961755 | 2.019598 |
| root均等候補 | 0.784013 | 0.664473 | 0.995009 | 2.025220 |
| 深さ領域均等候補 | 0.815846 | 0.669780 | 0.986582 | 2.026831 |

交差検証全体では現行モデルの数値が最も良い。新候補は `誤差/sigma のRMS` が1に近い一方、sigma自体のRMSEとGaussian NLLは現行より大きい。

## 再現方法と生成物

```powershell
python benchmark/mpc_depth_aggressiveness_20260830/end_generic_model_refit/run_constrained_analysis.py `
  --constraint-method bernstein `
  --output benchmark/mpc_depth_aggressiveness_20260830/end_generic_model_refit/results_constrained
```

- `coefficients.csv`: 最終2候補の6係数
- `coefficient_grid.csv`: 全事前分布強度の6係数
- `domain_audit.csv`: 最終2候補の全添字検査
- `domain_audit_grid.csv`: 全候補の全添字検査
- `cv_summary.csv`: 交差検証
- `holdout_metrics.csv`: 独立holdout
- `cut_simulation.csv`: cut simulation
- `results.json`: 上記の機械可読な統合結果
