# Issue #640 日本語定石名の照合結果

2026年10月28日に、[Issue #640](https://github.com/Nyanyan/Egaroucid/issues/640)で指定された[othlog「オセロ定石の名前と由来」](https://othlog.hasera.net/book-name/)と、更新前の日本語定石名を照合した。既存データの基準はコミット`a6b292166`。

## 追加内容

- 既存355局面の名称を維持し、未登録の343局面を追加した。定石名の登録は合計698局面。
- 次の定石候補を表示する`openings_fork.txt`も再生成し、801行から1,134行になった。
- 実行用リソースと配布用テンプレートの両方を更新した。
- サイトの個別記載422項目と、4手目の説明欄にだけ記載されている「猿」1項目を確認した。この423項目のうち、63項目は既存の登録盤面、360項目は未登録の盤面に対応した。
- 同じ盤面になる対称形や手順違いをまとめると、新規登録は343局面になる。新規項目同士で呼称が異なる場合は、両方を`/`で併記した。例：`牛素南/牛素北`、`墜落/モップ`。

盤面の照合と重複の判定には、GUIの`Opening::init()`と同じ4通りの対称形を使った。90度回転のように、初期盤面の黒白配置を交換する変換は含めていない。名称では読み仮名を省き、全角英数字と括弧を半角にそろえた。方向を表す「上」「下」「横」「縦」などの括弧は残している。
