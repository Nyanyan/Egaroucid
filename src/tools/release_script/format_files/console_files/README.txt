Egaroucid for Console by Takuto Yamana
Please visit https://www.egaroucid.nyanyan.dev/ for more information.
Source code: https://github.com/Nyanyan/Egaroucid

At the normal interactive prompt, use "chthread N" to change the thread count without restarting.
N is a positive integer including the main thread. For example, "chthread 4" selects four threads; "chthread 1" selects one.
