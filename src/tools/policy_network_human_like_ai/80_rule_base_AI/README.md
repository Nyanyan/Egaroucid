手作りの43特徴量の重みを、オセロクエストの着手者レート[800,1000)のデータで学習する実験です。全合法手へ得点を付け、softmaxで着手確率を出します。評価では確率最大の手を選び、同点ではビット番号の小さい手を採用します。ビット番号はa1=63、b1=62、a2=55、h8=0です。

特徴量には、マスの種類、C・X打ちに対応する隅の所有状態、返す石数、最多・最少取り、返す方向数と最長の列、着手後の双方の合法手数、相手が次に取れる隅の数、パス、着手マスの周囲の石、空きマスに接する石数の増減、辺上の石と隅から連続する辺の石の増加を使います。また、相手石に隣接する空きマス数を潜在的な合法手数として、その増減も使います。探索木は展開しません。

各特徴量に序盤・中盤・終盤の3係数を持たせるので、計129パラメータです。盤上の石数nからt=(n-4)/60を計算し、3組の重みを[max(1-2t,0),1-|2t-1|,max(2t-1,0)]で混ぜます。個数を定数で割るなど特徴量を正規化しているため、係数を読む際は[rule_policy.py](rule_policy.py)も参照してください。

既存の棋譜単位の分割を維持し、学習560,909局面、検証31,087局面、テスト30,423局面を使いました。分割間の棋譜ID重複を検査しています。学習は局面を均等に扱う交差エントロピーとL2正則化です。L2係数0.0001と0.00001を各最大120反復試し、検証の対称性を考慮した一致率が最良の重みを選びました。同率なら人間着手の負の対数尤度が小さい方を選びます。テストは選択に使いません。回転・鏡映で対応する手の特徴量と確率が同じになるため、8通りの水増しは目的関数と勾配が同じです。同じ計算を8回せず元局面で学習しました。val/testは水増ししていません。

同じテスト全30,423局面の一致率は、学習したルール46.53%、手作業のルール40.44%、最多取り32.75%、一様ランダムの期待値23.29%、既存の追加学習Conv8+BNが50.53%、Questのみで学習した既存Conv8+BNが50.35%でした。一致率では、予測した最大確率の1手が、人間着手または盤面の自石・相手石を変えない回転・鏡映でその着手を変換した手なら正解とします。NNの保存済み着手は、同じ順序のテスト局面と棋譜IDを照合して再集計しています。今回のルールは手作業の重みから6.09ポイント改善しましたが、既存NNを上回りませんでした。

レベル21の平均石損は、同じテスト全30,423局面の保存済みの最大確率手で計算します。Egaroucid for Console 7.8.1 SIMD、book無効、置換表保持、最大8プロセス・各1スレッドです。setboard、play、analyzeで選択手と最良の他の手の評価を取得し、max(選択手評価,他の最良手評価)-選択手評価を平均します。両評価は着手した側から見た予測石差です。これはL21推定値による1着手あたりの損失です。合法手1つの局面は0石損とし、重複局面も元の回数だけ分母に含めます。欠測を0に置き換えません。平均石損の結果は[results_summary.json](results_summary.json)のdisc_loss_l21へ記録します。statusがpendingの間は計算中です。
