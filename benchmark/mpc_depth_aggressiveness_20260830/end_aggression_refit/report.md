# 終盤MPCの枝刈り確率を強めた比較

## 比較内容

終盤の深い探索深度10～18、MPC level 74%・88%・93%を対象にした。浅い探索深度は全候補で現行表 `4, 5, 4, 5, 4, 7, 6, 7, 6` に固定した。

比較したのは、現行levelの標準正規分布上のz値 `1.13, 1.55, 1.81` に対する倍率である。z倍率を小さくすると残す中央確率が下がり、浅い探索値が枝を切る境界を越えやすくなる。

重要なのは、既に整数へ丸めた誤差幅へ倍率を掛けていないことである。各候補について次の順序で計算した。

1. 現行の浅い探索深度で得た `exact_value - shallow_value` を残差とした。
2. 標準偏差モデルは `gap_shallow`、shrinkage 64、平均モデルは `exact_value = shallow_value + residual` として学習した。
3. 候補の実際の両側中央確率をz倍率から計算した。
4. その確率に対応する上下の残差分位点を、丸め前の正規化残差から取り直した。
5. 整数誤差幅を `ceil(1.10 × tail × sigma)` で作り直した。

z倍率候補の実際の確率は次の通りである。「両側中央確率」は標準正規分布で `-z` から `+z` に入る確率を指す。

| z倍率 | 74% level: z / 両側中央確率 | 88% level: z / 両側中央確率 | 93% level: z / 両側中央確率 |
|---:|---:|---:|---:|
| 1.00 | 1.1300 / 74.1524% | 1.5500 / 87.8858% | 1.8100 / 92.9704% |
| 0.98 | 1.1074 / 73.1879% | 1.5190 / 87.1238% | 1.7738 / 92.3904% |
| 0.96 | 1.0848 / 72.1990% | 1.4880 / 86.3249% | 1.7376 / 91.7719% |
| 0.94 | 1.0622 / 71.1855% | 1.4570 / 85.4884% | 1.7014 / 91.1132% |
| 0.92 | 1.0396 / 70.1474% | 1.4260 / 84.6132% | 1.6652 / 90.4127% |

## 標準偏差モデルとデータ分割

z倍率の候補間では標準偏差を変えていない。4開発セットの交差検証と6月holdoutでは、現行の浅い探索深度に対して再学習したp0モデルを共通で使用した。4開発セットの各foldでは、確認対象以外の3セットだけで標準偏差と分位点を学習した。6月holdoutでは4開発セット全部で学習した。

admission補助holdoutでは、4開発セットにadmission学習側24 rootを加えてp0モデルを再学習し、残り11 rootだけを確認した。この補助データは過去の方針調整で使用済みなので、新しい独立holdoutではない。

## cutと推定ノード数

表の「cut合計」は静的評価だけのcutと浅い探索後のcutの合計である。「誤cut」は、cutした側に完全読みの値が実際には入っていなかった回数である。「2石以上」「4石以上」は、境界からの外れ幅がそれぞれ2石以上、4石以上だった誤cut数である。

「推定nodes」は、各contextについて `浅い探索を実行した場合の浅い探索nodes + cutできなかった場合の深い探索nodes` を合計した値である。収集済みの浅い探索nodesは置換表を空にしたfull-window探索であり、実際のMPCのnull-window探索とは一致しない。したがって、実測時間ではなく候補間のオフライン比較値である。
